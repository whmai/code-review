# 数据访问与安全门禁

## 查询性能与容量

- 数据库查询不能放在循环中；批量查询后用内存索引关联，避免 N+1。
- 列表、搜索、排序、筛选和关联必须有分页或边界，不能无上限读取。
- 在获授权的非生产环境检查关键查询索引与执行计划；性能门槛来自需求、既有 SLO 或确认预算。没有预算时记录基线与待确认项，不虚构阈值。
- 压测只在隔离环境进行，并设定并发、数据规模、时长和停止条件。

## 安全与数据可靠性

- 按适用性审查认证、授权、跨用户/租户对象访问、服务端输入验证、参数化查询、安全文件处理和错误信息泄露。
- 密码、令牌、个人信息及敏感请求体不得出现在日志、测试证据或不必要的响应中。
- 对写入、异步或并发流程审查事务、幂等、重试、重复消息、失败补偿、乱序和竞争；以可执行状态机、守恒或关联完整性检查验证。
- 仅在获授权环境进行安全验证，不对生产、第三方或非授权账户执行攻击式载荷、扫描或高频压力。
