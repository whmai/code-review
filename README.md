# Code Review

面向 AI 编程助手的代码审查 Skill，专注于后端架构、复用、代码放置、模块接口、性能实现、安全编码、注释、可观测性、常量和枚举。

它不替代业务验收。功能是否满足需求、页面/API/数据是否正确，应使用 [business-verify](https://github.com/whmai/business-verify)。后端功能开发通常同时使用两个 Skill：先用本 Skill 约束实现质量，再用业务验证 Skill 验证用户结果。

## 使用

```text
Use $code-review to review this backend change before delivery.
```

适合的自然语言触发包括“代码审查”“后端开发规范”“重构设计”“检查复用和文件放置”“检查日志、枚举或常量”。
